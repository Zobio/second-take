# second-take

LLMの回答がいまいちだったとき、**ワンクリックで別のLLMに聞き直せる** Chrome 拡張機能です。

Claude / ChatGPT / Gemini の画面右下にボタンを表示します。押すと、それまでの会話をまるごと別のサービスの新しいチャットに引き継ぎ、追加の入力なしで自動的に送信します。良い回答が返ってきたら、そのまま切り替え先で会話を続けられます。

## 対応サービス

| サービス | URL |
| --- | --- |
| Claude | https://claude.ai |
| ChatGPT | https://chatgpt.com |
| Gemini | https://gemini.google.com |

どのサービスからでも、他のどのサービスへでも聞き直せます。

## インストール

Chrome ウェブストアには未公開です。以下の手順で読み込んでください。

1. [Releases](../../releases) から最新の `second-take-x.x.x-chrome.zip` をダウンロードして展開する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選ぶ

## 使い方

1. 対応サービスのどれかで会話する
2. 画面右下の「別のAIに聞き直す」を押し、聞き直したいサービスを選ぶ
3. 右隣に新しいタブが開き、会話が自動で送信される

引き継ぎ先のサービスには、あらかじめログインしておいてください。

## 注意事項

- 各サービスの画面（HTML）を読み取り・操作して動いています。サービス側の画面が変わると、動かなくなることがあります。
- Web 画面を拡張機能から自動操作することは、各サービスの利用規約上グレーな面があります。自己責任でご利用ください。
- 会話の内容は、あなたのブラウザ内で引き継ぎ先のサービスに渡されるだけで、外部のサーバーには送信しません。
- 現時点では文章のみを引き継ぎます。添付ファイル・画像・プロジェクトの資料などは引き継がれません。

## 開発

[WXT](https://wxt.dev) で作られています。

```sh
pnpm install
pnpm dev     # 拡張機能を読み込んだ Chrome が起動する
pnpm build   # .output/chrome-mv3 に本番ビルド
pnpm zip     # 配布用の zip を作成
```

### 構成

```
entrypoints/
  background.ts      タブを開き、引き継ぐプロンプトを一時保存する
  llm.content.ts     全サイト共通: ボタン表示と、受け取ったプロンプトの自動送信
providers/           サービスごとの違い（画面の目印・操作）をここに閉じ込める
  claude.ts / chatgpt.ts / gemini.ts
utils/               どのサービスでも共通の処理
```

### 新しいサービスを追加するには

1. `providers/` に `Provider` インターフェース（`providers/types.ts`）を満たすファイルを作る
2. `providers/index.ts` の一覧に登録し、`ProviderId` に ID を足す

それだけで、そのサービスが送り元にも送り先にもなります。

### 画面が変わって動かなくなったら

該当する `providers/*.ts` の冒頭にある `SEL`（要素を探す目印）を直してください。
